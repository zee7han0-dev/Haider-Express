# Haider Express
1. Install Node.js (nodejs.org), open this folder in a terminal.
2. `npm install` then `npm run dev`  (open the link it shows)
3. Edit `src/data/products.js`: set your WhatsApp number, add products and photos.
4. `npm run build` creates the `dist` folder to upload to Netlify, Vercel or your hosting.
